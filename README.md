# AI_Project
Actividad formativa GitHub Copilot

## Descripción
En este laboratorio exploramos el uso de GitHub Copilot para la creación de un sistema de recomendación utilizando Python y bibliotecas como pandas y scikit-learn.

## Pasos realizados
1. Creación del Repositorio: Se creó el repositorio remoto `AI_Project` en GitHub.
2.Clonación del Repositorio: Se clonó el proyecto de forma local utilizando el terminal de Visual Studio Code.
3. Generación del Código: Con la ayuda de GitHub Copilot, se creó el script `recommendation_system.py` que entrena un modelo de clasificación KNN para recomendar productos.
4. Archivo de Datos: Se creó un archivo `products.csv` para alimentar el modelo.
5. Subida a GitHub: Se realizaron los comandos `git add`, `git commit` y `git push` para guardar todo en el repositorio remoto.
